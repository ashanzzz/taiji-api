# 太极 API 控制台界面说明

`public/` 提供无依赖的中文管理界面。它是一个同源、cookie 会话驱动的运维控制台，不是对 OpenAI API 的兼容性承诺。

## 页面与接口

| 页面 | 主要接口 | 行为 |
| --- | --- | --- |
| 登录 | `POST /admin/login` | 管理密钥仅留在登录表单中，不使用 `localStorage`、URL 或日志保存。成功后依赖 `HttpOnly` 同源 cookie。 |
| 概览 | `GET /admin/state` | 只展示服务端提供的安全状态信息。 |
| 模型 | `GET /admin/models` | 查看模型及其已声明能力；调试台据此启用推理选项。 |
| 调试台 | `POST /admin/playground` | 支持 JSON 和 OpenAI 风格 SSE；`content`、`reasoning_content` 均只通过 `textContent` 追加。停止按钮使用 `AbortController`。 |
| 兼容性测试 | `GET/POST /admin/tests`、`POST /admin/tests/:id/cancel` | 创建前明确确认上游成本，运行任务每 3 秒轮询。 |
| 设置 | `PUT /admin/settings`、`POST /admin/checkin` | 密码留空即保持原值；可信主机需明确列出才允许向其发送网站凭据。 |
| 日志 | `GET /admin/logs` | 日志字段以纯文本显示，详情被截断。 |

所有请求使用 `fetch(..., { credentials: 'same-origin' })`。控制台不读取或展示管理密钥、转发 API 密钥、账号密码或已保存密码。

## 兼容性测试的解释边界

- 上下文长度以**字符**计，而不是 token。通过一个字符边界只表示该边界内的请求成功，**不是最大上下文能力**。
- 推理探针会发送原始候选参数，并报告服务端保留的“接受”和“实际生效”证据。收到响应、`think` 标签或 `reasoning_content` 均不能单独证明模型进行过真实推理。
- 输出探针同时观察 `max_tokens=32` 与所选上限。上游可能接受参数但不执行限制；界面会展示返回输出 token 和服务端结论，而不把这解释为强制生效。
- 默认三个字符边界为 `1000,4000,8000`，默认最多 3 次请求。完整基线可将请求上限提高到 6；单个上下文边界最大 100000 字符。
- 调试台的输出上限默认留空。即使填写，当前上游实际输出仍可能按服务端固定策略处理（目前为 400），因此它只适合观察兼容性，不应作为额度保证。

测试任务可以返回 `queued`、`running`、`completed`、`failed`、`cancelled`，以及 `interrupted`、`error` 等非标准状态；界面会按原始结果显示而不把未知状态伪装成成功。

## 可访问性与响应式行为

- 所有表单控件有可见标签、帮助文字、焦点环和提交后行内错误。
- 侧栏在窄视图转换为水平导航；键盘用户可使用“跳到主要内容”。
- 图标使用内联 SVG；动态响应、日志和结果使用纯文本 API，避免 HTML 注入。
- 右下角“界面微调”可切换标准或紧凑显示密度，仅改变当前文档的视觉间距，不保存任何认证信息。
